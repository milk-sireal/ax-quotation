# AX러닝랩 견적서 생성기

기업 AX 교육 견적서 작성 웹 앱입니다. 공급자와 고객사 정보, 견적번호, 날짜, 교육 품목을 수정하면 견적서 미리보기가 즉시 갱신됩니다.

## 개발 및 검증

Node.js 22 이상에서 실행합니다. 앱 실행에 별도의 패키지 설치가 필요 없습니다.

```sh
npm run dev
npm test
npm run build
```

로컬 개발 서버의 기본 포트는 3000입니다. 빌드 결과는 `dist/`에 생성됩니다. 빌드 결과를 확인할 때는 개발 서버를 중지한 후 `node scripts/serve.mjs dist`를 실행합니다.

브라우저 통합 테스트는 Python Playwright, Chromium, Poppler의 `pdfinfo`와 `pdftotext`가 필요합니다. 빌드 결과 서버를 실행한 상태에서 다음 명령을 사용합니다.

```sh
CHROMIUM_PATH=/usr/bin/chromium python3 tests/browser.py
```

Playwright가 관리하는 Chromium을 사용하려면 `CHROMIUM_PATH`를 생략합니다. 서버 주소를 변경하려면 `QUOTE_URL`을 지정합니다.

## 작성 및 인쇄

- 수량과 단가는 0 이상의 정수입니다. 품목 표에서 각 칸을 직접 편집하고, 행 추가 버튼으로 품목을 추가할 수 있습니다. 할인율은 기본 0%이며 0~100% 범위에서 소수점 둘째 자리까지 입력할 수 있습니다. 할인 금액을 원 단위로 반올림해 공급가액에서 차감한 뒤 부가세 10%를 계산하고 원 단위로 반올림합니다.
- 처음에는 예시 품목이 표시됩니다. 작성 내용과 품목 삭제 내역은 현재 브라우저의 localStorage에 자동 저장됩니다. 다른 브라우저나 기기에는 동기화되지 않습니다.
- **인쇄 / PDF 저장**을 누른 뒤 브라우저 인쇄 창에서 A4를 선택합니다. PDF 파일이 필요하면 프린터 대상에서 **PDF로 저장**을 선택합니다. 브라우저가 페이지 주소나 날짜를 표시하면 인쇄 옵션에서 머리글과 바닥글을 끌 수 있습니다.

## Vercel

저장소 루트를 프로젝트 루트로 지정하면 `vercel.json`의 빌드 명령이 `dist/`를 생성합니다. 배포에 환경 변수, 로그인, 데이터베이스, 외부 API가 필요하지 않습니다.
